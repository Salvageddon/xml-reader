# xml-reader
XML reader library for C.

# note:

To use the reader in your project simply include the headers and xmlReader.dll. It also requires list library to be included and linked with the project.
There's a main.c included in this repo for you to try and test the library.
Remember that destructors MUST be corresponding to the type of the list item.
The one root element constraint doesn't happen here. You can have multiple roots in your xml file.
